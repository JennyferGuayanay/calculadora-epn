# Calculadora académica EPN

Aplicación web en HTML, CSS y JavaScript puro para evaluar dos aportes calificados sobre 20 puntos cada uno.

## Reglas implementadas

- Con 28/40 o más se aprueba directamente.
- Desde 18/40 y hasta menos de 28/40 se habilita el examen de recuperación.
- Con menos de 18/40 no se aprueba ni se habilita recuperación.
- Para aprobar mediante recuperación, el promedio entre la nota acumulada y el examen debe ser al menos 24/40.

Abre `index.html` en un navegador moderno. No requiere instalación ni dependencias.
